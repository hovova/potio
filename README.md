# Potio

Potio is an interactive mixology learning app focused on drink recipes, ingredients, bartender knowledge, and quiz-based learning.

The app is inspired by the reusable structure of Stella, but Potio has its own identity: a warm recipe-book / bartender-academy interface, full drink recipe cards, ingredient filters, favourites, and practical mixology quiz modes.

---

## Core Features

- Drinks encyclopedia with full recipe cards
- Recipe details: ingredients, glass type, ice, method, garnish, taste profile, origin, difficulty, and allergy notes
- Free filters for base spirit and drink type
- Free quiz modes planned:
  - Recipe Guess
  - Picture Match
  - Build the Drink
  - Mixology Trivia
  - Daily Mixology
- Free Basic Bar Academy campaign:
  - 20 levels
  - 50 popular drinks
- Premium plan:
  - 100+ total drinks
  - Master Mixologist Academy
  - Full bartender guide
  - Offline access
  - No ads

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/hovova/potio.git
cd potio
```

### 2. Install dependencies

```bash
flutter pub get
```

### 3. Run the app

```bash
flutter run
```

For Android development, make sure an Android emulator or Android device is connected and authorised.
